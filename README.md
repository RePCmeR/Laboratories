### Домашняя работа 4 (Нейронные сети)
🔗 [Ноутбук с работой](https://github.com/RePCmeR/Laboratories/blob/main/Labs/homework-practice-02-linregr-Perevalov_Daniil.ipynb)

**Стек:** PyTorch, Numpy, Pandas, Sklearn, Matplotlib, tqdm, librosa

**Что сделано:**
- **Часть 1. SPINN для 3D-уравнения Гельмгольца**
  - Реализовал класс `BaseSPINN` с тремя независимыми body-сетями (по одной на координату x, y, z) и CP-объединением.
  - Написал методы `forward` (вычисление на декартовой решётке) и `forward_pointwise` (произвольный набор точек).
  - Обучил модель на коллокационной сетке, минимизируя PDE‑loss и boundary‑loss.
  - Добился относительной L2‑ошибки на тесте порядка 1e‑3.

- **Часть 2. CNN‑классификация звуков UrbanSound8K**
  - Предвычислил мел-спектрограммы для всех аудиофайлов, сохранил их на диск для ускорения экспериментов.
  - Построил свёрточную нейросеть (Conv2D + пулинг + dropout + полносвязные слои) для классификации 10 классов звуков.
  - Провёл кросс‑валидацию по 10 папкам датасета, подобрал гиперпараметры (размер спектрограммы, число слоёв, learning rate).
  - Достиг accuracy на тестовой выборке 0.72. Построил confusion matrix и графики обучения.
