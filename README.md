### Домашняя работа 6 (Бустинг)
🔗 [Ноутбук с работой](https://github.com/RePCmeR/Laboratories/blob/main/ml/Домашняя%20работа%206/homework_practice_06_boosting-PerevalovDaniil.ipynb)

**Стек:** Numpy, Pandas, Sklearn, XGBoost, LightGBM, Optuna, Seaborn, Matplotlib

**Что сделано:**
- Реализован собственный класс градиентного бустинга `BoostingClassifier` с возможностью:
  - настраивать базовую модель (деревья решений), количество итераций, скорость обучения;
  - использовать раннюю остановку с отслеживанием метрики на валидации.
- Добавлена поддержка категориальных признаков:
  - целевое кодирование с отсортированными объектами (ordered boosting) для избежания утечки целевой переменной.
- Реализованы методы регуляризации и ускорения:
  - Bootstrap (Bernoulli и Bayesian) с контролем доли выборки;
  - GOSS (Gradient‑based One‑Side Sampling) — отбор объектов с большими градиентами;
  - RSM (Random Subspace Method) — случайный подмножество признаков на каждом дереве.
- Реализованы два способа вычисления важности признаков:
  - по числу сплитов (`type="split"`);
  - по суммарному приросту качества (`type="gain"`) с использованием структуры деревьев.
- Добавлена возможность использования Focal Loss для работы с несбалансированными классами.
- Проведён подбор гиперпараметров с помощью Optuna.
- Эксперименты с бустингом линейных моделей:
  - сравнение XGBoost с линейным бустером и SGDClassifier; показано, что XGBoost обучается значительно быстрее и достигает лучшего качества.
- Использована библиотека LightGBM с интеграцией в Optuna (включая pruning) для оптимизации регуляризации (`reg_alpha`, `reg_lambda`) и структуры деревьев.
